**# 🚀 Game Optimizer (Beta 1.0)

**Game Optimizer** is a lightweight desktop application built in Python (`customtkinter`) designed to help gamers quickly benchmark their PC hardware, analyze system bottlenecks, and predict exact game settings and frame rates based on live Steam data.

![App Preview](https://via.placeholder.com/900x500?text=Game+Optimizer+UI) *(You can replace this with an actual screenshot link later)*

---

## ✨ Key Features

* **Quick System Benchmarking:** Multi-threaded performance tests for your CPU, RAM, and GPU.
* **Live Steam Integration:** Type any game name to instantly fetch official requirements and capsule artwork via the Steam API.
* **Smart Bottleneck Detection:** Automatically analyzes your hardware ratios to warn you if your CPU or RAM is holding back your GPU.
* **Tailored Profiles:** Generates three distinct profiles (**Performance**, **Balanced**, and **Maximum Ultra**) complete with specific settings and FPS predictions.
* **Advanced Settings:** Toggle AI Frame Generation, Ray Tracing, or switch FPS display formats (Ranges, Averages, or Minimums) on the fly.
* **Reddit Export:** One-click formatting to copy your hardware specs, app scores, and test results directly to your clipboard for easy feedback sharing.

---

## 📥 Installation & Usage

1. Go to the [Releases](../../releases) tab on the right.
2. Download the latest `GameOptimizer.exe` file.
3. Run the executable directly (no Python installation or dependencies required).
4. Hit **"Run Benchmarks"**, type your favorite game, and hit **Optimize**!

## 🔒 Antivirus Notice (False Positives)
Because this tool is packaged into a standalone `.exe` using **PyInstaller** without a paid commercial code-signing certificate, a few minor antivirus vendors may flag it as a *false positive*. 
* Rest assured, the source code is entirely clean, and you can verify the binary using [VirusTotal](https://www.virustotal.com).
